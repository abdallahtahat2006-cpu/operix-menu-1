# قاعدة البيانات — Supabase

نظام مطعم واحد، بثلاث واجهات على نفس المشروع: منيو العميل، شاشة الصالة، لوحة التحكم.

## الملفات

| الملف | شو بيعمل |
|---|---|
| `01-schema.sql` | الجداول + الفهارس + التريغرز + RLS + Realtime. شغّله أول شي. |
| `02-seed.sql` | بيانات البداية (المطعم، ٤ أقسام، ١٥ صنف، ٢٤ طاولة) — مولَّد من `data.js`. |
| `03-storage.sql` | bucket الصور `menu` وصلاحياته. |
| `generate-seed.mjs` | يعيد توليد `02-seed.sql` من `data.js`: `node db/generate-seed.mjs` |

## الخطوات بالترتيب

1. أنشئ مشروع جديد على [supabase.com](https://supabase.com) واختر أقرب Region (Frankfurt أو Bahrain للأردن).
2. **SQL Editor** → الصق `01-schema.sql` → Run. (بدون أخطاء = تمام)
3. الصق `02-seed.sql` → Run.
4. الصق `03-storage.sql` → Run.
5. **Authentication → Providers → Anonymous Sign-ins → فعّلها.**
   جهاز العميل بيسجّل دخول مجهول تلقائياً، وهيك RLS بتعرف تربط كل طلب بجهاز صاحبه،
   وما بتقدر طاولة تقرأ طلبات طاولة ثانية.
6. **Authentication → Users → Add user** — أنشئ مستخدم للموظف (إيميل + كلمة سر، وفعّل Auto Confirm).
7. ارجع على SQL Editor ونفّذ (بدّل الإيميل والاسم):
   ```sql
   select public.grant_staff('manager@lumiere.com', 'المدير', 'manager');
   ```
   الأدوار المتاحة: `waiter` / `cashier` / `manager`. المدير وحده يقدر يضيف موظفين.
8. **Project Settings → API** → انسخ `Project URL` و `anon public` وحطهم في
   `supabase-config.js` بجذر المجلد.

## اللي بدي إياه منك بعد ما تخلص

- `Project URL` و `anon public key` (منيح تشاركهم، مصمّمين ليكونوا بالمتصفح).
- إيميل مستخدم الموظف اللي أنشأته (بدون كلمة السر — بس عشان أعرف مين بيدخل).
- تأكيد إنه Anonymous Sign-ins مفعّلة، وإنه الملفات الثلاثة اشتغلت بدون أخطاء.
- الدومين اللي رح ينزل عليه المنيو (لو موجود) — بينحط بـ `base_url` عشان أكواد QR تطلع صح.

**لا ترسل أبداً** مفتاح `service_role` ولا كلمة سر قاعدة البيانات — الأول بيتخطى كل قواعد الأمان،
والثاني ما بحتاجه إطلاقاً.

## ملاحظات أمان

- كل الجداول عليها Row Level Security:
  - **العميل** (دخول مجهول): يقرأ المنيو والإعدادات، ينشئ جلسة لطاولته، يرسل طلب/نداء/طلب فاتورة،
    ويقرأ **طلباته هو فقط**.
  - **الموظف** (له صف في `staff`): يقرأ ويحرّك كل شي بالصالة.
  - **المدير**: كمان يضيف ويشيل موظفين.
- تقدّم حالة الطلب (تأكيد → تحضير → جاهز → تقديم) محصور بالموظفين فقط.
- `qr_token` بكل طاولة: بينحط برابط الـ QR عشان ما يقدر حدا يفتح جلسة على طاولة بمجرد تخمين `?table=12`.

## بعدين (اللي رح أعمله أنا)

- `supabase.js` + طبقة `OPS` جديدة تقرأ وتكتب من Supabase بدل localStorage، مع Realtime بدل الـ polling.
- شاشة تسجيل دخول للموظفين على `staff.html` و `admin.html`.
- رفع صور الأصناف من لوحة التحكم مباشرة على bucket الصور.
- إبقاء الوضع المحلي شغّال لما تكون `supabase-config.js` فاضية (عشان العرض بدون إنترنت).
