# Operix Restaurant System

نظام مطعم متكامل يعمل من المتصفح: العميل يمسح QR الطاولة ويطلب، الموظف يستقبل كل شيء على شاشة
الصالة، وصاحب المطعم يدير المنيو والطاولات والإعدادات من لوحة التحكم.

> الفكرة ليست "QR Menu" بل:
> **Digital Menu + Table Service + Ordering + Staff Management + Restaurant Management**

## الواجهات الثلاث

| الصفحة | لمين | شو فيها |
|---|---|---|
| `index.html` · `menu.html` · `item-detail.html` | العميل | تصفّح المنيو، سلة، إرسال الطلب للمطبخ، تتبّع الحالة، خدمات الطاولة، الفاتورة والدفع |
| `staff.html` | الويتر والكاشير | لوح الطلبات (مراجعة → مطبخ → جاهز → تقديم)، التنبيهات، خريطة الطاولات، إشغال طاولة وطلب يدوي، الدفع |
| `admin.html` | صاحب المطعم | نظرة عامة، إدارة المنيو والأقسام، الطاولات وأكواد QR، الخدمات، طريقة وصول الطلب للمطبخ، بيانات المطعم |
| `system.html` | — | صفحة تجميع بتوصل للثلاثة |

عربي/إنجليزي كامل مع `dir=rtl`، وضع ليلي ونهاري، وتصميم متجاوب للجوال.

## التشغيل

بدون build وبدون مكتبات خارجية. افتح `system.html` مباشرة، أو:

```bash
node serve.js
```

ثم افتح `http://localhost:4321`. السيرفر اختياري وبيلزم بس لتجربة أكواد QR من الجوال.

## قاعدة البيانات

حالياً النظام بيشتغل على طبقة محلية (localStorage) بتخلي الواجهات الثلاث تتزامن بين تبويبات المتصفح،
والانتقال لـ Supabase جاهز: راجع [`db/README.md`](db/README.md) للـ schema وسياسات الأمان وخطوات الربط.
بعد التنفيذ، حط `Project URL` و `anon key` في `supabase-config.js`.

> `supabase-config.js` ما بيحمل أسرار: مفتاح `anon` مصمّم ليكون بالمتصفح، والحماية كلها عبر
> Row Level Security. لا تضع `service_role` فيه إطلاقاً.

## بنية الملفات

```
index.html / menu.html / item-detail.html   واجهة العميل
staff.html + staff.js                       شاشة الصالة
admin.html + admin.js                       لوحة التحكم
system.js                                   الحالة المشتركة + ناقل التغييرات (OPS)
console-core.js + console.css               الطبقة المشتركة للواجهتين الخلفيتين
script.js                                   محرّك واجهة العميل
data.js                                     كل المحتوى (المطعم، الأقسام، الأصناف، الترجمات)
qr.js                                       توليد أكواد QR داخل الصفحة
style.css                                   نظام التصميم
db/                                          schema و seed وسياسات Supabase
```
